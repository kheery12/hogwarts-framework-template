## Common Commands

| Task | Command |
|------|---------|
| Run tests | `npm test` or `pytest` (auto-detect framework) |
| Check types | `tsc --noEmit` or `mypy .` |
| Lint code | `npm run lint` or `ruff check` |
| Format code | `prettier --write .` or `black .` |
| Build project | `npm run build` or `python -m build` |
| Start dev server | `npm run dev` or `python manage.py runserver` |

## File Patterns

| Pattern | Location |
|---------|----------|
| Tests | `tests/` or `__tests__/` or `**/*.test.ts` |
| Config | Root level: `.eslintrc`, `tsconfig.json`, `pyproject.toml` |
| Environment | `.env`, `.env.local`, `.env.production` |
| Documentation | `docs/`, `README.md` |
