# Ravenclaw Skills

Specialized planning and architecture skills.

## Available Skills

| Skill | Purpose | Trigger |
|-------|---------|---------|
| skill-creator | Create new skills | "create skill", "new skill" |
| doc-coauthoring | Structured documentation | "write docs", "documentation" |

## Adding Skills

New skills for Ravenclaw must:
1. Focus on planning, research, or architecture
2. Follow standards in `references/skill-standards.md`
3. Pass Slytherin review before deployment
